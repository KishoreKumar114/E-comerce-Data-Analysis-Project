# Project Title

🛒 E-Commerce Data Analysis & Dashboard – Python + Power BI

# Project Overview

This project analyzes E-commerce sales data using:

🐍 Python for data scraping, cleaning, and processing

📊 Power BI for interactive visualization


The dashboard provides actionable insights on sales trends, product performance, pricing, and customer feedback, helping businesses make data-driven decisions.

# Dashboard Structure

📄 Page 1 – Sales Overview & KPIs

📈 Last month’s sales by product

📅 Month-wise sustainability tags

📊 Sales trend over the last month

🎯 Sales targets vs. actuals

⭐ Product rating analysis

🗂 Category-wise sales distribution


📄 Page 2 – Product Catalog Analysis

🛍 View all products with details

🔍 Compare product performance across multiple metrics


📄 Page 3 – Product Detail & Pricing Analysis

🏷 Product-level insights with categories

💲 Actual price vs. discounted price

⭐ Product ratings & reviews

🏆 Best-selling products

💰 Total sales per product


# Tools & Technologies

🐍 Python – Data scraping, cleaning, preprocessing

📊 Power BI – Interactive dashboards & visualization

📁 CSV / Excel – Dataset storage


# Key Insights

🥇 Identified top-selling products and categories

📈 Tracked sales trends and deviations from targets

⭐ Highlighted products with high ratings and customer satisfaction

💸 Analyzed the effect of discounts on sales performance


# How to Use

1. 📥 Download Ecommerce_Analysis.pbix from this repository.


2. 🖥 Open in Power BI Desktop.


3. 🔎 Explore the 3-page interactive dashboard:

Page 1: Sales KPIs & Trends

Page 2: Product Catalog

Page 3: Product & Pricing Details
